speak 語音回覆技能

把結論用自然的台灣中文語音唸出來 — 行內、無視窗、與打字並行

Claude Code · 全域技能

這是什麼

達成「使用者語音輸入 → Claude 語音回覆」的對話循環。以微軟免費的 Edge-TTS 生成台灣中文語音，串流邊生成邊播，全程不開任何外部播放器視窗。

三層備援構造

第 1 層｜串流模式（預設，最快） speak.ps1 → speak_stream.py → Edge-TTS 串流 → mpv/ffplay 管道播放 首聲約 1 秒、不落地、無視窗 │ ▼ 第 2 層｜整檔模式 Edge-TTS 生成 mp3 → MediaPlayer(COM) → 退 WMPlayer(COM) │ ▼ 第 3 層｜SAPI 離線備援 Windows 內建語音（零延遲、免網路）

原理

  • TTS 引擎：微軟 Edge-TTS，免費、線上、音質自然
  • 為什麼快：非同步串流，每塊音訊一生成就塞進播放器管道，收到就出聲
  • 為什麼無視窗：mpv/ffplay 管道 + COM 物件播放，絕不用 Start-Process
  • 與打字並行：背景執行，語音與文字回覆同時發生

使用

pwsh -NoProfile skills/speak/speak.ps1 "要唸的文字"
echo "要唸的文字" | python skills/speak/speak_stream.py - zh-TW-YunJheNeural

環境需求

元件用途備援
Python + edge-tts語音生成無 → 退 SAPI
mpv 或 ffplay串流播放無 → 退整檔 COM
網路Edge-TTS 連線無 → 退離線 SAPI
PowerShell 7執行 speak.ps1PS 5.1 需 UTF-8 BOM
