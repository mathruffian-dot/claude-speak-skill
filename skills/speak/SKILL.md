# speak — 快速語音回覆

## 用途
把一段結論／摘要用自然的台灣中文語音唸出來，達成「使用者語音輸入 → Claude 語音回覆」的對話循環。

- 生成＋播放：**預設串流**（Edge-TTS 邊生成邊播，首聲約 1 秒；ffplay/mpv 管道播放，無視窗）
- 備援鏈：串流 → 整檔（MediaPlayer/WMPlayer COM）→ SAPI 離線；絕不 `Start-Process` 開播放器
- 三師爸聲音（VoxCPM2）**只在使用者明確指名時**改走 `voice-clone` 技能

## 執行步驟

### 1. 撰寫講稿
- 口語化、精簡（100–250 字），數字用中文（「五十頁」不要「50頁」）
- 只講結論與下一步，細節留在文字回覆

### 2. 生成＋播放（一條指令，⚡預設用背景執行）
```powershell
pwsh -NoProfile "<本技能資料夾>\speak.ps1" "<講稿文字>"
```
（`<本技能資料夾>`＝本 SKILL.md 所在目錄，即技能載入時顯示的 base directory）

**背景平行（重要）**：使用者要「文字回完的當下語音就接上」——所以呼叫時**用 `run_in_background: true` 丟到背景**，緊接著開始寫文字回覆；語音會在你打字的同時播放。背景完成通知回來時，把輸出裡的 `first_sound_s`／`total_s` 順帶回報。

其他選項：
- 長稿改 `-File "<講稿.txt>"`
- 預設聲音 `zh-TW-YunJheNeural`（男）；女聲 `-Voice zh-TW-HsiaoChenNeural`
- 使用者說「存起來」→ 加 `-Out "<專案路徑>.mp3"`（走整檔模式並保留音檔）
- 串流不產生檔案；需要檔案時才用 `-Out`

### 3. 回報
一句話帶過即可（模式、首聲延遲、音檔位置若有存）。不要重複唸稿內容。

## 注意
- 使用者句子含「三師爸的聲音」「用○○的聲音」→ 不用本技能，改用 `voice-clone`
- Edge-TTS 需要網路；離線時自動退到 Windows SAPI（機器感較重但零延遲）
- 不要用 `Start-Process` 播放——會開外部程式視窗，使用者明確不要
